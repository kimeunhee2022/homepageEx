# 홈페이지 화면 시제품

`index.html`을 브라우저에서 열면 볼 수 있습니다. 인터넷 연결이나 설치가 필요 없습니다.

- 상단 작품 수 1·2·3 버튼으로 초기 콘텐츠 양에 따른 구성을 비교합니다.
- 작품 이미지를 누르면 캐릭터·그림책·포스터 상세 화면으로 이동합니다.
- 화면 너비를 줄이거나 휴대전화에서 파일을 열면 모바일 구성을 확인할 수 있습니다.
- 그림·제목·소개 문구는 화면 시험을 위한 예시이며 실제 보유 작품이 아닙니다.
- 원본 PRD는 수정하지 않았습니다. Wix 사이트 및 관리 기능은 아직 제작하지 않았습니다.
- 문의 전송, 댓글, 초안 저장, 관리자 기능은 구현 범위에 포함되지 않습니다.

## 검토할 내용

1. 작품 1개만 있을 때도 전시로서 자연스러운지
2. 여백과 작품 크기, 글자 크기가 편안한지
3. 세 가지 작품 형식이 하나의 홈페이지 안에서 어울리는지
4. 임시 이름과 소개 문구가 원하는 분위기에 가까운지

검토 후 화면을 조정하고, Wix에서 실제 등록·수정 및 공개 설정을 검증하는 단계로 이어갑니다.
